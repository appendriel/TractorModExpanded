# Release notes

## 1.0.1
- Fixed the grain harvester not harvesting the base game's wheat, corn, rice and amaranth when no other mod adds grain tags to them (the produce harvester also harvested them in that case). The base game's grains are now always recognized.
- Tested with TractorMod Expanded as the only mod installed.

## 1.0.0
- First release.
- Implements: plow, seeder, water tank (3 levels), rock breaker (2 levels), wood cutter (2 levels), produce, grain, bush and fruit tree harvesters, mower.
- Blueprint hitch menu (I), upgrades at Clint, the implement always returns when you leave the tractor.
- New tractor in 3 colours, modern garage, implement sprites, icons, effects and working animations.
- English and Portuguese.
